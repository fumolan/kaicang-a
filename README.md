# 📈 A股开仓

> T+1 · 无杠杆 · 简单算收益 — A股模拟交易看板

**在线使用**: https://fumolan.github.io/kaicang-a/

## 功能

- **全市场行情**: 沪深北A股列表(东财接口可用时约5900只, 受限时自动降级131只核心池), 实时价格来自腾讯行情(不封IP)
- **四大指数**: 上证指数 / 深证成指 / 创业板指 / 沪深300
- **市场总览**: 涨跌家数 / 涨停跌停级统计 / 涨幅·跌幅·成交额·换手四大榜单
- **个股详情**: T-1昨收 / 今开高低 / 换手振幅 / PE·PB / 总市值·流通市值 / 涨跌停价
- **历史K线**: 近250交易日日K(前复权) + MA20 + 近5/20/60/250日区间统计
- **模拟交易**: T+1规则(当日买入次日可卖) · 整百股 · 佣金万2.5(最低5元) · 印花税万5(卖出) · 过户费万0.1
- **收益追踪**: 持仓浮盈实时刷新 / 已完结交易胜率与净收益统计

## 说明

- 纯静态页面, 数据实时来自腾讯/东财公开接口, 无需登录
- 交易记录保存在**自己的浏览器**里(localStorage)
- 刷新间隔默认30秒(交易时段内), 可调60秒/3分/手动
- 仅供学习研究, 不构成投资建议
